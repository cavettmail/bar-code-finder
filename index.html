How to use

First time

  1. Open the link in Chrome (Safari on iPhone).
  2. Tap Add to phone so it opens like a regular app.
  3. Allow the camera when asked.

Find a bottle that won't scan

  1. On Find, tap Snap a bottle.
  2. Fill the frame with the front label, held straight. Include the bottle's barcode if you can.
  3. Tap the match that's right. The app remembers it, so it gets faster for everyone.
  4. Scan the big barcode on the card with your scanner. Tap it to go full screen and turn your brightness up.

No luck? Type the producer or name in the search box instead.

Add bottle photos

  • Open any item and tap Add photo, or Use the photo I just took after a snap.
  • Photos are shared with the team and help the app recognize bottles.
  • Tick Only items without a photo to see what's left.

Count

  1. Find an item and type its count on the card, or use +1 / −1.
  2. Open bottles use decimals: 3.4 means 3 full plus about 4 tenths.
  3. The Count tab shows totals by sheet page. Copy it or download a spreadsheet when you're done.
  4. Start a new count clears it. Counts stay on your phone only.

Bottle not on the sheets?

  1. Tap Not on the sheets? Add it to the No SKU list after a snap, or use Add a bottle on the No SKU tab.
  2. Add a short note (name, size).
  3. The whole team sees the list. Tap SKU added once it's set up, or Copy list to send it on.

New inventory sheets

  1. On Sheets, tap Upload new sheets. Excel or CSV works best.
  2. Confirm which column is the item code, name, and so on.
  3. Check what's added and removed, then tap Use this list. It updates for everyone.

Share with the team

Tap Share app and send the link. It has the team code built in, so don't post it publicly.
